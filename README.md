## Completed Projects

### Task 1 - Exploratory Data Analysis on Retail Sales Data

Exploratory analysis of 50,000 retail transactions to identify sales trends, customer behaviour, product performance, and actionable business insights.

**Tools:** Python, pandas, matplotlib, seaborn, and Google Colab.

[View Task 1](./DataAnalytics-L1-EDARetailSales/)

### Task 2 - Customer Segmentation Analysis

RFM customer segmentation using K-Means clustering on 541,909 online-retail transaction records. The project identifies Champions, Regular Customers, Promising customers, and Hibernating customers and recommends a targeted marketing strategy for every segment.

**Tools:** Python, pandas, NumPy, scikit-learn, matplotlib, seaborn, and Google Colab.

[View Task 2](./DataAnalytics-L1-CustomerSegmentation/)
